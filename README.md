# Curso Java: Practicando condicionales con if/else

Este repositorio contiene los ejercicios prácticos desarrollados durante el curso **"Practicando Java: condicionales con if/else"**, ofrecido por **Oracle** y **Alura Latam**.  
Este curso fue impartido por el instructor **Eric Monné Fraga de Oliveira**.

El objetivo principal fue fortalecer el uso de estructuras condicionales en Java mediante la resolución de desafíos de lógica y validación, esenciales para el desarrollo de aplicaciones robustas.

## Descripción

Durante el curso, se trabajaron los siguientes temas fundamentales:

- Operadores relacionales y lógicos
- Estructuras condicionales: `if`, `else if`, `else`
- Validaciones de entrada y lógica de decisión
- Uso del paquete `Scanner` para entradas por consola
- Separación de lógica en clases específicas para cada problema

A lo largo del curso, se implementaron **10 ejercicios**, cada uno enfocado en un caso práctico común en programación.

## Proyecto: Condicionales con if/else

Los ejercicios resueltos fueron los siguientes:

1. ✅ Verificación de número par o impar  
2. ✅ Verificación de aprobación en una asignatura  
3. ✅ Validación de contraseña  
4. ✅ Comparación de dos números  
5. ✅ Aplicación de descuento en compras  
6. ✅ Verificación de día hábil  
7. ✅ Verificación de si un número está en un intervalo  
8. ✅ Verificación de si tres lados forman un triángulo  
9. ✅ Verificación de compatibilidad para donar sangre  
10. ✅ Verificación de código de acceso y nivel de permiso

Cada uno de estos ejercicios se encuentra implementado como una clase Java, y se ejecutan desde la clase principal `Main.java`.

## Tecnologías utilizadas
- **Java**: Lenguaje principal utilizado.
- **JDK 17.0.6**: Versión de Java Development Kit.
- **IntelliJ IDEA**: Entorno de desarrollo utilizado.

## Requisitos

- Tener instalado [Java JDK 17.0.6](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html)
- Un IDE como IntelliJ IDEA, Eclipse o VS Code con soporte para Java

## Cómo ejecutar el proyecto

1. Clona este repositorio en tu máquina local
2. Abre el proyecto en tu IDE favorito.
3. Navega al archivo `Main.java`.
4. **Descomenta** el bloque de código del ejercicio que deseas ejecutar.
5. **Comenta** los demás bloques de código para evitar conflictos, especialmente aquellos que usan `Scanner`.
6. Ejecuta la clase `Main` como una aplicación Java.

### ⚠️ Importante:
Debido a que algunos ejercicios utilizan entradas por consola, es necesario comentar y descomentar bloques de forma manual. Esto evita interferencias entre ellos.

## Lo aprendido en este curso

- Aplicación de estructuras condicionales para tomar decisiones lógicas
- Uso eficiente de operadores lógicos y relacionales
- Captura de datos desde consola con `Scanner`
- Organización de código mediante clases y métodos
- Simulación de situaciones reales como: validaciones, descuentos, y permisos
